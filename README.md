## 🚀 Projects

### ☁️ CloudVault – Smart Cloud Storage on AWS
**Tech:** AWS EC2, S3, Lambda, API Gateway, IAM, CloudWatch • Python 3.12 (boto3) • HTML, CSS, JavaScript

A cloud storage app where a user uploads a file on a web page and it is **automatically sorted into the right S3 bucket** (images, videos or documents) by file type.

- Website hosted on **EC2 with Apache**, with drag-and-drop upload, live progress, speed and time left.
- **Lambda** checks the file extension, picks the bucket and returns a **pre-signed URL**, so large videos upload straight to S3 without hitting Lambda or API Gateway size limits.
- Buckets stay private, and the Lambda role only has `s3:PutObject` on the three buckets.
- Unique keys with date folders, so files with the same name never overwrite each other.

👉 [View the project](https://github.com/Shaikmajidali/AWS_projects/tree/main/CloudVault)
